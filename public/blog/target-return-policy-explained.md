# Target Return Policy Explained: 90 Days, 365 for Target Brands

## Quick Answer

Target offers a generous 90-day return window on standard items, extended to 120 days for Target Circle Card holders. Target-owned private labels (Cat & Jack, Threshold, Good & Gather) carry a 365-day satisfaction guarantee.

## Key Policy Facts

| Policy Metric | Details | Status |
|---|---|---|
| **Standard Return Window** | 90 Days from purchase | yes |
| **Target-Owned Brands Window** | 365 Days (1 Full Year) | yes |
| **Target Circle Card Extension** | +30 Extra Days (120 Days total) | yes |
| **No-Receipt ID Limit** | $150 Max per calendar year | warning |
| **Cellular Phone Restocking Fee** | $35.00 Fee on opened contract phones | no |

## Can I return Target items without a receipt?
Yes. Target can perform a receipt-free lookup if you paid with a Target Circle Card, major credit/debit card, Target GiftCard, or scanned your Target Circle barcode at checkout. If Target cannot locate your transaction digitally, you can present a valid government-issued ID for a Merchandise Return Card up to Target's annual limit of **$150 per shopper per calendar year**.

## What is Target's return policy for electronics?
Most electronics and entertainment items have a **30-day return window** (extended to 60 days for Circle Card holders). **Apple products carry a strict 15-day return window** with no card extension allowed.

## Does Target charge a restocking fee?
Target does **not** charge restocking fees on general merchandise, open clothing, or electronics. The only exception is opened contract cellular phones, which carry a **$35 restocking fee**.

## How does Target handle gift returns without the original receipt?
Gift returns accompanied by a gift receipt or Target Gift Registry printout can be returned for a Target GiftCard. Returns from a Target Baby or Wedding Registry can be returned up to **365 days after the event date**.

## What happens if I return an item after Target's deadline?
Target's registers block returns once the applicable 90-day, 120-day, or 30-day window passes. The 365-day Target-owned brand policy is the main exception for items like Cat & Jack or Good & Gather.

## Step-by-Step Return Instructions

1. **Confirm your return window**: Check whether the item falls under the standard 90-day window or the 365-day Target-brand window.
2. **Start the return**: Use Target.com or the app to generate a free return label, or bring the item to Guest Services.
3. **Get your refund**: Refunds go to the original payment method; no-receipt returns may be issued as store credit.

## Frequently Asked Questions

### How long is Target's return window?
Target's standard return window is 90 days for general merchandise. However, if you purchased Target-owned private labels (such as Cat & Jack, Good & Gather, or Threshold), you get a full 365-day return window with proof of purchase.

### Do Target Circle members get extra time?
Yes. Target Circle members (free loyalty tier) and RedCard holders receive a 30-day return window extension, pushing standard items to 120 days.

### What is the famous Target 'Cat & Jack' return policy?
Target offers a 1-year satisfaction guarantee on all Target-owned brands, including Cat & Jack baby and kids' clothing. You can return worn or outgrown Cat & Jack items within 365 days of purchase for a full refund or exchange with receipt or Target app barcode.
