## Quick Answer

Nike offers the most lenient policy for tested footwear, giving Nike Members 60 days to return worn shoes. DSW allows 90 days (and up to 365 days for Gold VIPs) for unworn shoes. Foot Locker enforces a strict 45-day window requiring undamaged original sneaker boxes.

## Key Policy Facts

| Policy Metric | Details | Status |
|---|---|---|
| **Nike Member Worn Shoe Window** | 60 Days (Allowed even if worn) | yes |
| **Foot Locker Return Window** | 45 Days (Unworns in original box) | yes |
| **DSW VIP Member Return Window** | 90 to 365 Days depending on VIP tier | yes |
| **Nordstrom Return Policy** | Case-by-case evaluation without strict cutoff | yes |

### Pro Tips for Sneakerheads & Shoe Shoppers
- **Do not tape shoe boxes**: When mailing a shoe return to Foot Locker or DSW, place the shoe box inside an outer shipping box or bag. Taping directly onto the branded shoe box ruins resale value and voids the return.
- **Join Nike & DSW VIP Programs**: Membership is free and grants extended return windows, paperless receipt lookups, and free return shipping labels.


## Step-by-Step Return Instructions

1. **Keep the Original Shoe Box Intact**: Never attach shipping labels directly onto the manufacturer's shoe box.
2. **Test Shoes Indoors First**: Walk on clean carpet indoors to verify fit and comfort before wearing outdoors.
3. **Return In-Store or via Member Portal**: Drop off at any physical store location for free instant card refunds.

## Frequently Asked Questions

### Can you return worn sneakers to Foot Locker?
No. Foot Locker strictly requires sneakers to be unworn, in new condition, and packaged inside the original, undamaged shoe box.

### Can you return worn sneakers to Nike?
Yes! As long as you are logged into a free Nike Member account, Nike allows you to test out shoes and return them within 60 days even if they have been worn outdoors.

### What happens if I destroy the original shoe box?
Foot Locker and DSW require original packaging. If the original shoe box is missing or heavily damaged, store associates may reject the return or charge a repackaging penalty.
