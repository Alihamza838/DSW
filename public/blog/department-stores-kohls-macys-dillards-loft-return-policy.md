# Department Store Return Policies: Kohl's, Macy's, Dillard's & Loft Compared

## Quick Answer

Kohl's leads major department stores with a generous 180-day return window and paperless receipt lookup. Macy's provides 90 days for standard apparel. Dillard's requires items to be returned within 30 days with proof of purchase, and Loft accepts returns within 30 days.

## Key Policy Facts

| Policy Metric | Details | Status |
|---|---|---|
| **Kohl's Standard Return Window** | 180 Days (6 Months) | yes |
| **Macy's Standard Return Window** | 90 Days from purchase date | yes |
| **Dillard's Return Window** | 30 Days with proof of purchase | warning |
| **Kohl's Amazon Drop-off Service** | FREE drop-off + bonus Kohl's coupon | yes |

### Insider Department Store Tips
- **Kohl's Coupon Hack**: Dropping off an Amazon return at Kohl's yields an instant printed store coupon (often 15% off or $5 Kohl's Cash), which can be redeemed on same-day purchases.
- **Dillard's Yellow Tags**: Dillard's attaches a distinct yellow proof-of-purchase sticker to garments. Removing this sticker can void return eligibility, so keep it attached until you're certain you'll keep the garment.


## Step-by-Step Return Instructions

1. **Verify Department Store Receipt**: Locate paper sales slip, email confirmation, or scan your store rewards account.
2. **Check Department Return Cutoffs**: Ensure items fall within 180 days for Kohl's, 90 days for Macy's, or 30 days for Dillard's and Loft.
3. **Drop Off at Customer Service Desk**: Present item and ID at customer service desk for instant card credit or store gift card.

## Frequently Asked Questions

### Which department store has the longest return policy?
Kohl's features a 180-day (6-month) return window for non-premium electronics, making it one of the most customer-friendly policies in retail.

### Can I drop off Amazon returns at Kohl's for free?
Yes! All Kohl's store locations accept free Amazon return drop-offs without needing a box or tape, and they frequently issue a 15% Kohl's store coupon upon drop-off.

### What is Dillard's return window?
Dillard's has a strict 30-day return window from the date of purchase. Items must be in original condition with yellow proof-of-purchase tags attached.
