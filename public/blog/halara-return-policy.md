## Quick Answer

Halara allows returns within 30 days of delivery. Items must be unworn, unwashed, and in original packaging with hygiene seals intact. Return shipping fees are paid by the customer unless Halara made a fulfillment error.

## Key Policy Facts

| Policy Metric | Details | Status |

| **Standard Return Window** | 30 Days from delivery date | yes |
| **Return Method** | Mail returns only (Online portal) | neutral |
| **Return Shipping Fee** | Customer pays return label fee | warning |
| **Clearance / Final Sale** | Non-returnable | no |
| **Underwear & Swimwear** | Hygiene liner & tags must be intact | warning |
| **Refund Without Return** | Offered on select low-value damaged items | yes |

## How Does Halara's 30-Day Delivery Return Window Work?

Unlike traditional brick-and-mortar stores that count from purchase date, Halara's **30-day return window** starts on the **exact date package delivery is confirmed by tracking**.

---

## Does Halara Charge Return Shipping Fees?

Halara does **not** offer free return shipping for standard return reasons (sizing, change of mind, style preference).

- Return shipping fee will be deducted from your final refund amount when generating a shipping label via the portal.
- **Defective / Wrong Item Exception:** If Halara shipped the wrong size, wrong color, or a defective garment, contact customer care for a $0 fee return label or full replacement.

---

## Which Items Are Non-Returnable Final Sale at Halara?

The following items cannot be returned under Halara policy:
- Final Sale / Clearance items marked explicitly at checkout
- Free gifts or promotional giveaways
- Intimate wear and bodysuits missing hygiene liners
- Items returned without original tags or with pet hair, perfume, or makeup stains

## How to Initiate a Return on Halara

1. Go to **thehalara.com** and navigate to the Return Portal.
2. Enter your order number and email address.
3. Select the items you wish to return and specify the reason.
4. Download and print the pre-paid return shipping label.
5. Pack items securely in original poly-mailers with tags intact.
6. Drop off package at designated local postal carrier.


## Step-by-Step Return Instructions

1. **Log In to Halara Account / Order Lookup**: Visit the Halara return portal on thehalara.com and enter your order number and email.
2. **Select Items & Reason**: Choose the items you wish to return and indicate fit or quality reasons.
3. **Print Return Label & Pack Package**: Attach Halara return shipping label onto original bag with tags intact.
4. **Drop Off & Track Package**: Hand package to designated carrier (USPS/DHL). Refund issues within 5-7 days of warehouse inspection.

## Frequently Asked Questions

### How long do I have to return items to Halara?
Halara gives you 30 days from the date your package was delivered to submit a return request on their online portal.

### Does Halara cover return shipping costs?
No. Unless you received a damaged, defective, or incorrect item, return shipping label costs are deducted from your refund total or paid directly by the buyer.

### Can I return Halara dresses or shorts if I removed the tags?
Items missing original tags or showing signs of wash/wear are ineligible for return and will be rejected by Halara's warehouse.

### How does Halara handle international returns from UK, CA, and AU?
International customers follow the same 30-day portal process, but local return carrier fees apply depending on country of origin.

### What is Halara's refund without return option?
For certain low-value or slightly damaged items, Halara customer support may offer a partial gift card refund or replacement without requiring you to ship the item back.
